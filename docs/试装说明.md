# Chunkly 试装说明

## 一、加载插件

产物目录：`/Users/a19150/Project/chunkly/apps/extension/dist`
（已复制一份到 `/tmp/chunkly-dist`，内容相同，路径随便挑一个）

1. Chrome 打开 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择上面那个 `dist` 目录
4. 记下生成的扩展 ID（后面取 Key 时用不到，但出问题时有用）

> 如果之前装过旧版本：**先点旧版本上的「重新加载」图标**，不用删掉重装。
> 改了 `content.js` 之后还必须**刷新当前网页**，否则页面里跑的还是旧脚本。

## 二、配置 API Key（只需一次）

你的 key 在这里：`~/.config/magpie/plugin-auth.json` 的 `commandcode-plan.key`

取出来：

```bash
python3 -c "import json;print(json.load(open('/Users/a19150/.config/magpie/plugin-auth.json'))['commandcode-plan']['key'])"
```

然后：

1. 点扩展图标 → 打开设置页（或右键扩展 → 选项）
2. 选 **CommandCode** 预设
3. 把 key 粘进 API Key
4. 模型填 `deepseek/deepseek-v4.1-flash`，推理强度选 **off**
5. 保存

> **`off` 很重要**：切分是浅层句法任务，开 thinking 质量不变但延迟翻倍
> （实测 3974ms → 1967ms）。CommandCode 的 deepseek 支持 `off`。

## 三、怎么试

选一段英文（任意网页），然后：

| 操作 | 效果 |
|---|---|
| `Alt+Shift+C` | 切分选中文本 |
| `Alt+Shift+Z` | 撤销高亮 |
| 右键 → 用 Chunkly 切分选中文本 | 同上 |
| 右键 → Chunkly：清除高亮 | 同上 |

**重点看这三件事**：

1. **虚线 → 实线**：选完立刻出现**虚线**框（规则法，5ms），约 2.4 秒后变成**实线**框（LLM 精确结果）。这是这次改动的主角。
2. **有没有跳变**：跳变幅度大不大、能不能忍。这是这套方案唯一的代价，我拿不准的就是这一点。
3. **再选同一段**：应显示「命中缓存」，**5ms 出准确结果**（不走虚线）。阅读时反复回看同一段是常态。

## 四、已知问题（别当 bug 报）

- **规则法那 2.4 秒可能不准**，尤其是长从句。虚线就是在提醒这个。
- **切分粒度偏粗**：平均 5.4 词/意群（LLM 是 4.9）。细粒度调节还没做。
- **只支持英文**。
- **必须是选中文本才能触发**，没有「整页自动切分」。
- **长文本（>600 字符）会拆段并发**，token 消耗是单次的 2–3 倍；延迟收益只有 1.1–1.25×
  （固定开销摊不掉）。这部分主要是为了**可靠性**——实测 12911 字的超长行单发会因为
  `max_tokens` 截断而失败，拆段并发能成功。
- **Chrome 155 起 `--load-extension` 命令行开关被禁用**，只能手动在 `chrome://extensions/` 里加载。

## 五、如果出问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 什么都没出现 | `content.js` 没注入 | 刷新网页 |
| 「无法连接后台」 | service worker 挂了 | `chrome://extensions/` 里点重新加载 |
| 「鉴权失败」 | key 错或过期 | 重新取 key |
| 「模型切分失败（已保留规则切分）」 | 网络/限流/模型返回异常 | 看虚线版是否还能用 |
| 一直显示「正在用模型优化…」 | 请求卡住 | 检查网络；超时会自动降级 |

**降级行为**：LLM 失败时**不会清掉虚线版**，会保留规则切分并提示。设计原则是「降级可读」好过「一片空白」。

## 六、反馈给我什么最有价值

按价值排序：

1. **虚线→实线的跳变有多烦**（能忍 / 忍不了 / 没注意到）—— 这决定这套方案要不要留
2. **规则法那 2.4 秒的切分够不够用**（能不能读 / 偶尔别扭 / 完全没法看）
3. **实际延迟感受**：从按键到看见东西，是不是真的「立刻」
4. 有没有**错位高亮**（高亮框和文字对不上）—— 这是 bug，不是体验问题
