Chunkly

英文网页意群切分。选中文本后按 ⌥⇧C 即可。

使用方式

官方开箱即用；想接自己的服务就选自定义。

官方模式已内置推荐模型。若在开源版或未配额度时，请切换至「自定义」填入自己的 API Key。

OpenAI 兼容接口的根地址，需支持 /chat/completions。

高亮视觉风格

选择最契合你阅读习惯的意群呈现方式，支持即时预览。

交互设置

划选英文文本时的辅助提示与触发行为。

选中文本后在光标附近展示悬浮按钮，点击直接切分，无需按快捷键。

!
快捷键可在 chrome://extensions/shortcuts 修改。 选中文本后也可右键使用菜单。
