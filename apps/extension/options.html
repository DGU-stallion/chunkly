Chunkly 设置

CommandCode（推荐）：直连 api.commandcode.ai/provider/v1，用你的计划 key（user_ 开头）。 自带额度、不限流，且支持 reasoning_effort=off 关掉 thinking（实测延迟从 3974ms 降到 1967ms，质量不变）。

GLM 预设已填好官方 API 地址与模型，需自行在 bigmodel.cn 申请 Key；免费额度实测频繁 429。

本地网关预设指向 http://127.0.0.1:3425/v1（magpie）。请求由 background 发出， 网关会看到 chrome-extension:// 而不是网页 origin。

意群切分是浅层句法任务，开 thinking 不会让结果更好，但会把延迟和 token 翻倍。 注意 GLM 不支持 off（传了会 400），所以选 GLM 预设时此项自动置空。
